# LLM 人格回測的雙層記憶污染 — 詳細分析報告

> 撰於 2026-07-19。本報告回答一個問題:**交易員人格辯論系統能不能對過去的行情做回測?**
> 結論先講:能回測的窗口由「模型知識截止日」決定,不由「ICT 語料有沒有講加密貨幣」決定。
> 相關文件:[Phase4_回測系統_規劃.md](Phase4_回測系統_規劃.md) §2.4、[preregistration.md](preregistration.md) §6、知識庫 [[LLM回測的雙層記憶污染]]。

---

## 1. 問題背景:為什麼 LLM 人格不能像機械策略一樣回測

機械化策略是一組數學規則。規則沒有記憶:丟給它 2023 年的資料,它只能誠實地按規則計算,所以歷史回測測的確實是「規則的預測力」(剩下的問題只是過擬合,有 DSR/PBO/MCPT 等工具處理)。

LLM 人格是**帶著記憶的判斷者**。丟給它 2023 年的盤面請它判斷方向,它的輸出可能來自兩個無法區分的來源:

1. 用蒸餾出的思維框架推理(我們想測的)
2. 從訓練記憶裡「回想起」那之後實際發生了什麼(污染)

兩者在輸出上**完全無法區分**——都是一段有模有樣的分析文字加一個方向。這是 LLM 版的 look-ahead bias,比數值策略的資料洩漏更隱蔽:數值洩漏可以用時間切割機械地排除,記憶洩漏藏在權重裡。

---

## 2. 第一層污染:人格語料的記憶(可稽核)

### 2.1 成因

ICT 人格由 537 支 YouTube 教學逐字稿蒸餾而成(`data/transcripts/ICT/`)。逐字稿不只教方法,也包含 ICT 對**當時實際盤面**的評論。若回測日期落在語料涵蓋期內,人格的判斷可能間接引用語料中對該時段行情的描述。

### 2.2 實測盤點(2026-07-19 偵察結果,第一手證據)

- 語料總數:538 個逐字稿檔案
- 最新一支:**2026-07-14**(五天前)——語料涵蓋期實際上一路貼到當下
- 2026 年的影片:**23 支**;標題抽查顯示絕大多數是 **NQ 期貨**的盤面評論(Futures Commentary / NQ Futures Review),非加密貨幣
- 2025 年的影片:65 支

### 2.3 為什麼可稽核

這層記憶是**顯性的、有限的、可枚舉的**:537 份文字檔就在磁碟上。稽核方法:

1. 掃描 2026 年(回測窗口內)的 23 支逐字稿全文
2. 檢查是否具體提及 BTC/ETH/bitcoin/ethereum 的價位、方向、日期
3. 有具體提及的日期從回測窗口剔除,並在報告中記錄剔除清單

ICT 主戰場是 NQ/ES 指數期貨,對 BTC/ETH 的具體評論預期很少——**稽核大概率會通過**。但要誠實記錄稽核的極限:

- 「稽核未發現提及」≠「零洩漏」,只是把風險降到可陳述的程度
- 間接洩漏仍可能存在:例如 ICT 評論 NQ 的 risk-on/risk-off 語境,間接透露了同時段的市場狀態(BTC 與 NQ 相關性不低)。這屬於殘留風險,報告必須揭露

---

## 3. 第二層污染:底層模型的權重記憶(不可清洗)

### 3.1 成因——人格是面具,面具下的大腦看過全部歷史

跑人格的不是 ICT,是 Claude(或任何底層 LLM)。模型的訓練資料涵蓋到其知識截止日(目前引擎:2026 年 1 月),其中包含**整個加密貨幣市場的公開歷史**:每一根大 K 棒、每次崩盤、每篇新聞、每個恐慌與狂熱的討論串。

因此:「ICT 沒講過 BTC」**推不出**「人格對 BTC 沒有記憶」。人格 prompt 只是行為約束(面具),不是記憶隔離(腦白質切除)。你請 ICT 人格判斷 2025-08-15 的 BTC,面具下的大腦可能直接記得那週後來的走勢——而且它不需要有作弊的「意圖」,記憶提取和框架推理在生成過程中是混在一起的。

### 3.2 為什麼不可清洗

- 記憶存在**權重**裡,不在資料裡。語料可以刪檔,權重不能選擇性刪除(目前不存在可靠的 machine unlearning 可用於此場景)
- **也無法驗證不存在**。可以做 probe 測試:盲問模型「2025-08-15 BTC 價格多少?之後一週漲跌?」——但 probe 的證明力是**單向的**:
  - 答得出來 → 證明污染存在 ✔
  - 答不出來 → **不能**證明判斷時不受隱性記憶影響 ✘(顯性回憶失敗 ≠ 隱性影響不存在;模型可能「說不出價格」但在判斷時仍偏向實際發生的方向)
- 統計上這是**無法證明的陰性**(unprovable negative)。預登記世界觀對此只有一種誠實的處理方式:**當作有污染**

### 3.3 推論:回測邊界由模型截止日劃定

大範圍回測的可用邊界不是「ICT 有沒有講過加密貨幣」(第一層邏輯),而是**底層模型的知識截止日**(第二層邏輯)。第一層可稽核、第二層只能繞開——繞開的唯一方式就是只用模型「物理上不可能記得」的日期:訓練截止日之後。

## 4. 時間軸三分區

```
──────────────┬──────────────────────┬─────────────┬──────→
   2026-01 以前      2026-02 ~ 07-14      07-14 之後
   模型記憶區          半乾淨區             真乾淨區
   (永久放棄)      (稽核後可探索)      (前瞻累積主線)
```

| 分區 | 污染狀態 | 可用性 |
|---|---|---|
| **2026-01 以前** | 第二層污染(模型記憶),無法清洗、無法驗證陰性 | **永久放棄**。樣本再多都是零價值,測的是「模型記不記得行情史」不是「框架有沒有預測力」,且污染幅度無法量化——連「打個折扣解讀」都做不到 |
| **2026-02 ~ 07-14**(約 164 個交易日) | 第二層物理上不可能(超出訓練截止);僅剩第一層(ICT 語料),可稽核 | **探索性支線**,四個前置條件見 §5 |
| **2026-07-14 之後** | 兩層皆無 | **主線**:每日前瞻累積(preregistration 已生效的唯一正式證據來源) |

---

## 5. 半乾淨區探索性回測的四個前置條件

1. **語料稽核先行**:掃 2026 年 23 支逐字稿,具體提及 BTC/ETH 價位/方向/日期者,對應日期剔除。稽核不過(大量提及)→ 整條支線放棄。
2. **回測 subagent 禁用一切工具**:實盤模式下 subagent 能不能上網無所謂(未來對誰都是未知);回測模式下,一個能用 WebSearch 的 subagent 可以直接查到「後來漲了沒」。回測 prompt 必須純文字、零工具。
3. **獨立的探索性預登記**:窗口、指標、稽核程序先寫死再跑,結果落 `backtest_runs` 表,**永遠標記 exploratory,永不併入主線樣本**。主線(前瞻累積)才有資格宣稱「系統有效」。
4. **鎖定模型 ID**:全程同一模型,model_id 落 DB。

### 賞味期限警告

此窗口依賴「現行引擎模型知識截止=2026-01」這個事實。**Claude Code 升級到更新截止日的模型後,窗口即縮水或消失**——半乾淨區是有期限的資產,要做要趁早。反過來說:每次模型升級,已跑的探索性回測不能用新模型「補跑」或「重跑」,那會把窗口性質整個改變。

---

## 6. 成本與可行性估算(2026-07-19 估)

- 單人格 R1-only:每筆判斷 = 一個 subagent,輸入 ≈ 15k tokens(ICT SKILL.md 27KB ≈ 12k + 摘要 + 指令),輸出 ≈ 500
- 全窗口:164 天 × 2 標的 = **328 次呼叫 ≈ 500 萬 input tokens**
- API 計價約 $15-20(prompt cache 命中可壓到數美元);Claude Code 訂閱額度下**單一 session 跑不完**,需分 4-5 批
- 「跑不完」不構成風險:落地層寫入即定案+unique constraint,天然支援斷點續跑,缺哪天補哪天
- **建議執行順序**:稽核 script → 探索性預登記 → 歷史摘要生成器(現行 ingestion 只抓最近兩天,需小改)→ **30 天 pilot**(60 筆,實測成本並先看有無訊號)→ 有訊號再分批跑滿

### 附帶收穫

探索性回測的樣本正好可餵 [preregistration.md](preregistration.md) §5 的 **Neutral 門檻敏感度分析**——讓未來門檻修訂有據可依,不必等主線慢慢累積。

---

## 7. 一句話總結

**機械策略的回測邊界由資料切割決定;LLM 人格的回測邊界由記憶決定——語料記憶可稽核,權重記憶只能繞開,所以可用窗口 = 模型知識截止日之後、且語料稽核通過的日期。**
