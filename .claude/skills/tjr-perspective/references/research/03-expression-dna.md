## 3. 術語體系（與 ICT 重疊者 + 他自己的講法）

**與 ICT/SMC 高度重疊的核心術語**（跨全部 16 批次通用）：liquidity sweep、break of structure (BOS)、fair value gap (FVG) / imbalance、inverse FVG、order block、breaker block、equilibrium（premium/discount）、draws on liquidity、low resistance liquidity / high resistance liquidity、SMT divergence（leading index / lagging index）、macro（9:50-10:10 時間窗，借自 ICT 但自行簡化定義）、kill zone、BPR（balanced price range）、79% Fib extension、session highs/lows（Asian/London/New York）。

**他自己的講法/再包裝**：
- 「draw(s) on liquidity」「low resistance draws on liquidity」「high resistance liquidity」——他把 ICT 的流動性概念口語化為自己最常掛嘴邊的招牌詞。
- 「price is fractal」：同一套 confluence 在任何時間框架都適用（自陳教學核心邏輯，非 ICT 原詞但概念相近）。
- 「the macro」：對 ICT 機械化 macro 理論保持距離，強調是憑經驗抓出的個人化時窗而非硬性法則（batch02, `r-7-gWZsnZc`）。
- 對 order block/breaker block 的態度隨時間推移由「必修 building block」演變為「completely useless, respectfully」「redundant」（batch05/08/10/14），只保留 liquidity sweep + BOS + equilibrium/FVG。
- 「accumulation candle」：他自創、明確表示不等同 order block 的替代詞（batch13）。
- 「seek and destroy」：自創命名的獵殺回踩現象（batch03/05/10/12/14/16）。
- 「daily profile」三分類法（前一 session 盤整→新 session 反轉；前一 session 操縱未反轉→新 session 反轉；前一 session 操縱+反轉→新 session 延續）：他對「如何找 daily bias」最系統化的自創教學框架（batch13, `e_FV0Q14k8E`）。
